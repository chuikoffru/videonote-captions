# Видео → кружочек: результат проверки

13 ноября 2026. Ветка `codex/video-to-circle`, код функции — `fd44308`.
Реализация завершена локально; production не обновлялся.

## Реализовано

- Обычное видео и видеодокумент → выбор кружочка без текста или с субтитрами.
- Без субтитров: 5 успешных результатов в день по Europe/Moscow, отдельная атомарная квота, без расхода кредитов и месячных субтитров.
- С субтитрами: существующие настройки месячного лимита/кредитов, без второй платы за конвертацию. Исходные кружочки по-прежнему сразу направляются на субтитры.
- Центральный кроп с учётом поворота/SAR, H.264/AAC, 384×384, до 60 секунд. Явное подтверждение обрезки длинного видео. HDR отклоняется до резерва с предложением SDR-экспорта.
- Повторные кнопки, владелец, чат, TTL меню, освобождение слота, возвраты, очистка файлов, раздельные метрики и RU/EN описание функции.

## Автоматические проверки

- `go test -race -p 1 -timeout 180s ./...` — PASS. Использована отдельная временная PostgreSQL 16, не production.
- Реальные FFmpeg/ffprobe: portrait/landscape/square, HEVC/MOV, поворот и кроп, звук и silent, ограничение длительности, отмена, 10-битный HEVC/PQ HDR.
- `TestRenderedWordDisappearsInPause` — PASS с настоящим libass; тест не пропущен. Проверены видимое слово и отсутствие субтитра в паузе.
- База: конкурентный лимит, идемпотентное завершение, возврат на исходную дату, граница московских суток, независимость кредитов/субтитров, раздельные логи и атрибуция.
- Обработчики: plain без ASR/кредитов, captions без дневной квоты plain, отказы по стадиям, long-video confirmation, busy menu и повторные/чужие/истёкшие callbacks.
- `go vet ./...` и `go build ./...` — PASS.
- Штатный `Dockerfile` — PASS с `GO_IMAGE=public.ecr.aws/docker/library/golang:1.25.6-alpine` и обычным runtime `alpine:3.23`. Проверен именно код `fd44308` после исправления из ревью.
- Smoke test runtime-образа: H.264 384×384/AAC создаётся непривилегированным пользователем в `/app/temp`; ffprobe, libass и Noto Sans доступны. Запуск без токена ожидаемо завершается на `BOT_TOKEN is required`, без обращения к Telegram.
- RU/EN страницы запущенного локального web-сервиса содержат правильный дневной лимит, новый блок и соответствующие deep links. HTML-маршруты, условия, приватность и feature flag покрыты тестами. Визуальная браузерная проверка не выполнена: инструмент открытия браузера завершился таймаутом.

## Независимое ревью

Один Important-дефект: при отмене processing context не отправлялся итоговый статус ошибки. Исправлен отдельным уведомлением с собственным таймаутом 5 секунд. `TestTimeoutSendsTerminalStatusAndRefunds` сначала воспроизвёл сбой, затем прошёл; после исправления общий набор тестов, vet, Go/Docker build прошли. Critical и Minor замечаний нет.

## Включение и оставшаяся приёмка

По умолчанию `ENABLE_VIDEO_TO_CIRCLE=false`. Для выпуска установить одинаковое
`ENABLE_VIDEO_TO_CIRCLE=true` у bot и web, `PLAIN_CIRCLES_PER_DAY=5`, пересобрать
сервис. В Dokploy bot читает `.env`, web получает публичные настройки Compose.
Новые таблица квот и поля логов добавляются существующим GORM AutoMigrate.
Откат функции — выключить флаг у bot и web; данные и старые субтитры сохраняются.

Не выполнялись: отправка в реальный Telegram, приёмка iOS/Android/Desktop,
реальные Whisper-запросы, платежи и production deployment. Автотесты используют
синтетические медиа и Telegram/ASR mocks; они не доказывают доставку реальному клиенту.

Принятые ограничения первой версии: кроп только по центру; начало длинного
ролика вместо произвольного таймкода; меню в памяти 30 минут и теряется после
рестарта. Аварийное восстановление резервов и неоднозначная отправка Telegram
требуют ручной сверки; автоматического повторного отправления нет.
