# Telegram Voice to Video Bot

Telegram-бот, который конвертирует голосовые сообщения в видео с визуализацией аудио, аватаркой пользователя и субтитрами.

## 🎨 Особенности

- 🎤 Принимает голосовые сообщения напрямую или через переадресацию
- 🎬 Создает MP4 видео в разрешении 720p
- 🌊 Неоновая визуализация аудиодорожки
- 👤 Круглая аватарка пользователя
- 📝 Автоматические субтитры с помощью OpenAI Whisper
- 🎨 Темный градиентный фон с неоновыми эффектами
- 📏 Крупный шрифт субтитров для удобного чтения

## 📋 Требования

- Node.js v16 или выше
- FFmpeg (устанавливается автоматически через `@ffmpeg-installer/ffmpeg`)
- Telegram Bot Token
- OpenAI API Key (для транскрипции аудио)

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone <url>
cd telegram-voice-video-bot
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните переменные окружения в файле `.env`:
```env
BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
```

### Получение токенов

**Telegram Bot Token:**
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

**OpenAI API Key:**
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ в `.env`

## 🎮 Использование

Запуск бота:
```bash
npm start
```

Запуск в режиме разработки (с автоперезагрузкой):
```bash
npm run dev
```

## 🛠️ Технологии

- **Grammy** - современный фреймворк для Telegram ботов
- **FFmpeg** - обработка и генерация видео
- **OpenAI Whisper API** - транскрипция голоса в текст
- **Canvas** - генерация дефолтных аватарок
- **Node.js** - серверная платформа

## 📝 Как работает

1. Пользователь отправляет голосовое сообщение боту
2. Бот скачивает аудиофайл
3. OpenAI Whisper транскрибирует аудио в текст
4. Бот загружает аватарку пользователя
5. FFmpeg создает видео:
   - Темный градиентный фон
   - Неоновая визуализация аудиодорожки
   - Круглая аватарка пользователя
   - Субтитры с неоновым свечением
6. Готовое видео отправляется пользователю
7. Временные файлы удаляются

## 🐛 Решение проблем

**Ошибка установки canvas:**
На macOS может потребоваться установка дополнительных зависимостей:
```bash
brew install pkg-config cairo pango libpng jpeg giflib librsvg pixman
```

**FFmpeg не найден:**
Пакет `@ffmpeg-installer/ffmpeg` должен установить FFmpeg автоматически. Если возникают проблемы, установите FFmpeg вручную:
```bash
brew install ffmpeg
```

**Ошибки OpenAI API:**
Убедитесь, что у вас есть кредиты на аккаунте OpenAI и API key действителен.
